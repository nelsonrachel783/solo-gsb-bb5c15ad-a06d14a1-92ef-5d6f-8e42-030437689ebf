# 纸张对折打孔展开预览

一个 Web 小工具：输入纸张宽高，依次指定沿当前折叠面水平/垂直中线对折（哪一侧折向另一侧），
在最终折叠面上点击打孔，系统按折叠顺序逆推出每个孔在原纸上的全部位置并实时预览展开图。

- 后端：Python Flask（几何计算 + SVG 导出）
- 前端：原生 SVG + 原生 JS，无任何前端依赖
- 重合孔位只画一次；孔落在折痕或纸张边界（或过近）时明确提示调整，不给出含糊结果

## 一条命令启动（Docker / Docker Compose）

```bash
docker compose up --build
```

该命令会自动安装依赖并启动服务。

- 访问地址：http://localhost:8000
- 端口：容器内固定为 `8000`，宿主机端口在 `docker-compose.yml` 的 `ports` 中修改
  （例如改为 `"8080:8000"` 后访问 http://localhost:8080）

停止：`docker compose down`。

## 必要配置

默认即可用，无需任何配置。可选项：

| 配置 | 位置 | 说明 |
| --- | --- | --- |
| 宿主机端口 | `docker-compose.yml` 的 `ports` | 默认 `8000:8000` |
| 容器内端口 | `Dockerfile` 的 `CMD`（gunicorn `--bind`）与 `EXPOSE` | 默认 `8000` |
| 本地开发端口 | 环境变量 `PORT` | 仅 `python app.py` 开发模式生效，默认 `8000` |

## 本地开发（不用 Docker）

```bash
pip install -r requirements.txt
python app.py          # 访问 http://localhost:8000
```

运行几何核心单元测试：

```bash
python -m unittest test_folding -v
```

## 使用说明

1. **纸张尺寸**：输入宽、高（单位 mm，范围 1–5000）。
2. **添加对折**：点击四个按钮之一，沿当前折叠面的垂直/水平中线对折，并指定哪一侧折向另一侧；
   可连续对折多次（最多 10 次），折法列表中可单独删除某一步或一键清空。
3. **打孔**：在左侧“折叠面”图上点击添加打孔点（可多个，最多 64 个）；点击已有孔附近可删除；
   孔半径可调。
4. **实时预览**：右侧“展开图”实时显示原纸上的全部孔位（红点）与折痕（蓝色虚线），
   修改折法或孔位后即时重算；重合位置只画一次，并在信息栏注明合并数量。
5. **边界提示**：打孔点落在折叠面的折痕边/纸张边缘上，或展开孔落在折痕、纸张边界上
   （距离小于 0.5 mm 视为过近）时，页面会给出提示，请调整孔位。
6. **下载**：点击“下载展开 SVG”导出展开图文件（尺寸以 mm 标注，可用于排版/切割参考）。

## 接口

- `POST /api/compute`：入参 `{paper:{w,h}, folds:[{axis,side}], punches:[{x,y}], hole_r}`，
  返回折叠面矩形、层数、折痕、去重后的孔位与警告列表。
- `POST /api/download`：同上的入参，返回 `unfolded.svg` 文件下载。
- `GET /api/health`：健康检查。

坐标约定：原纸左上角为原点，x 向右、y 向下；折叠面即原纸坐标系中的子矩形，
打孔点坐标直接在该坐标系中表达。
